# AWG Pilot для Chrome

Расширение открывает выбранные сайты (Gemini, Google, ChatGPT, Claude) через ваш сервер, а остальные — напрямую. Для этих сайтов оно подменяет геолокацию на Амстердам и не выпускает WebRTC мимо прокси.

Серверу нужен HTTP-прокси с логином: на VPS это вход `http` в Xray (порт 8880), с теми же маршрутами, что у подключения VLESS.

## Установка

1. Откройте `chrome://extensions` и включите «Режим разработчика» (справа вверху).
2. Нажмите «Загрузить распакованное расширение» и выберите эту папку `chrome-extension`.
3. Закрепите значок AWG Pilot на панели, откройте «Настройки» и укажите сервер, порт, логин и пароль.
4. Включите переключатель в окне расширения.

Логин и пароль хранятся только в этом браузере (`chrome.storage.local`). Прокси — обычный HTTP: содержимое сайтов зашифровано (HTTPS), но логин прокси передаётся открыто.
